# Dataset

This project uses the NBA Player Box Score Stats (1950-2022) dataset: game-level box
scores with 29 columns (player, team, date, minutes, shooting made/attempted, rebounds,
assists, steals, blocks, turnovers, points, plus/minus, and more).

The file is too large to store here (over GitHub's 100 MB limit), so it is not committed.
To run the scripts, download the dataset and save it in this folder as:

    data/NBA Player Box Score Stats (1950-2022).xlsx

Source: Kaggle, "NBA Player Box Score Stats (1950-2022)".
